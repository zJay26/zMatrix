# zMatrix 路线图

[返回首页](../README.md) · [验收证据](acceptance.md) · [反馈建议](https://github.com/zJay26/zMatrix/issues/new/choose)

当前阶段：**开发预览**。下面区分代码实现和真实平台验收，不承诺尚未确定的交付日期。

## 已实现的本地工作流

- [x] Markdown 编辑、配套图片导入与素材管理。
- [x] 母稿与平台版本、独立覆盖、差异提醒和内容快照。
- [x] 代码、表格、公式与图表预览。
- [x] 三种图文模板与多页图片生成。
- [x] 发布前预览、任务持久化、手动最终发布边界。
- [x] 文章链接登记、指标和评论缓存结构。
- [x] 本地自动保存、文件夹备份、ZIP 导出与校验恢复。
- [x] 稳定扩展身份、开发者模式安装、CI 和预览版打包。
- [x] 内容库组合筛选、排序、分页、列表视图与批量归档撤销。
- [x] 多窗口保存冲突保护、合并连续输入、失败后另存完整稿件副本。
- [x] 带相对图片路径的 Markdown 内容导出、当前版本导出和独立版本复制。
- [x] 专注／双栏／阅读视图、格式工具栏和发布队列筛选。

- [x] 稿件回收站、批量任务清理、独立防重凭据与未使用素材清理。
- [x] 平台按需添加、发布原位补字段、常用选择记忆与数据互动入口合并。
- [x] 发布登记修改和移除、清理期间的并发与备份兼容保护。
- [x] 点击触发的扩展更新：目录核对、包校验、工作空间与程序备份、失败恢复和重载协调。
- [x] 通用发布信息（标签、摘要、封面一次填写，各平台继承）、一步分发与多篇批量分发。
- [x] 总览页、平台账号页、内容库平台状态矩阵、按稿件分组的队列与数据汇总，浅色／深色外观。

## v1 验收重点

- [ ] 六条内容路径保存草稿，重开后内容与素材完整。
- [ ] 六条内容路径自动完成内容、素材及必填设置，停在最终发布前。
- [ ] 五站真实文章基础指标、评论与历史回复分页读取。
- [ ] LINUX DO 人工辅助流程与可行的聚合读取。
- [ ] 实际扩展刷新、浏览器重启和 MV3 后台终止后的任务恢复。
- [ ] 登录过期、上传失败、提交超时等异常流程不丢稿、不重复提交。
- [ ] 在实际 Edge 扩展中验证授权目录、备份恢复与复杂内容显示。
- [ ] 在实际 Edge 中完成安装目录授权及跨版本更新，核对重新加载、权限保持和数据保留。

未完成分类、标签、封面或中间页面时，保持“发布设置待核对”；只有核对齐全才能标记“等待手动发布”。模拟测试、截图和人工接管不替代这些验收。

## 当前 v1 范围之外

跨设备同步、团队权限、定时发布、AI 改写、自由画布、Word/PDF 或网页正文导入、历史文章自动收集、自动更新已发表正文、账号趋势分析、评论回复和管理操作。

这些是未来可讨论的方向，不是已承诺的开发计划。请用具体创作场景提出建议，优先说明现在的工作方式、重复操作和希望节省的步骤。
