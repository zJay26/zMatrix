# 内容管理与创作工作流

本文对应 v0.4.0 开发预览版中的本地功能；真实平台流程的验收状态见 [验收记录](acceptance.md)。

## 找到和整理稿件

- 搜索同时检查母稿标题、正文、平台独立标题与平台标签。空格分隔的词需要同时匹配，英文不区分大小写。
- 平台筛选匹配已经保存的平台版本或已经登记的发布记录。未编辑过的“跟随母稿”页签不会自动算成一份平台版本。
- “已登记发布”来自本地发布记录；它不表示本轮已重新读取原站。仅登记草稿的稿件仍属于“未登记发布”。
- 可按最近编辑、最近创建或标题排序，并切换卡片和列表。每页显示 24 篇，返回内容库时保留筛选、视图和页码。
- “选择本页”可以配合翻页累积选择；改变筛选条件会清空选择。批量导出和归档针对已选稿件。
- 归档保留正文、素材、平台版本与发布记录，也不会增加内容版本号。可立即撤销，或在“已归档”中移回内容库。
- 复制创建一篇新稿，保留母稿和已保存的平台独立版本，复用本地图片，不复制原稿的发布记录和任务。

- 稿件卡片上的垃圾桶或“删除所选”将稿件移入回收站，支持恢复；选中后可“选择全部结果”跨页处理。归档与复制位于卡片“更多”菜单。
- 删除稿件时会取消未开始的关联任务；执行中或结果待核实的任务须先到发布队列处理。恢复稿件不会自动恢复任务执行。
- 回收站中的“彻底删除”不可撤销，会移除母稿、平台版本和可清理的关联任务；发布登记独立保留并解除母稿关联，原站内容不受影响。图片需经素材清理核查引用后才删除。

## 设置与阅读

“设置”分为通用偏好、平台连接、数据与备份、软件更新。界面默认使用 16px 基准字号，正文编辑与预览默认 17px；两者可分别调整为 14–22px 和 14–26px。界面字号同时影响导航、按钮、标签和标题，字号预览与页面即时响应，偏好保存在本地，重新打开后恢复。

通用偏好可选择内容库默认卡片／列表视图、编辑器默认双栏／仅编辑／仅预览视图，并控制打开工作台时是否刷新文章数据。“恢复默认偏好”只恢复本页偏好，保留更新设置、备份目录和所有稿件。字体设置不改变导出图文卡片的固定排版。

软件更新默认每 6 小时检测公开 Release，提供手动检测与正式版／开发预览筛选。首次授权当前安装目录后，点击“立即更新”即可下载、校验、备份、替换文件并重新加载。其他工作台页面和未核实的发布任务须先处理完；安装期间锁住编辑与后台任务。0.3.0 及更早版本需手动升级一次，完整步骤见 [安装与更新](installation.md#更新)。

## 写作与保存

空白新稿在第一次编辑时才保存，直接返回不会留下空记录。编辑器默认显示母稿和本篇已添加的平台，点击“添加平台”创建跟随母稿的版本。平台设置与发布记录可按需展开；导出、图文制作和移除平台版本位于右上角“稿件工具”菜单。

“移除此平台版本”会清除独立标题、正文、配图和平台设置，母稿与原站内容保留。之后可重新添加平台。

平台版本中的分类使用下拉候选项：掘金提供核实过的固定分类；CSDN 分类专栏、博客园个人分类和 LINUX DO 分类可在原站展开选项后，点击“读取原站分类”。读取只查看已连接平台的现有标签页，不点击发布控件；无法识别时提示在原站处理。本地用过的分类单独列出，旧值保留，不表示已与当前账号的分类匹配。

标签按回车、中英文逗号或分号添加，可粘贴多个标签；重复标签自动合并，每项可单独删除。按 Ctrl+S 或切换平台时，正在输入但尚未回车的标签也会保存。中文输入法选字期间不会误添加标签。

“从正文提取”从当前平台实际正文的前两段文字提取最多 160 字，跳过标题、图片、代码块、公式和表格；可编辑或撤销提取。此功能在本地运行，不调用 AI 服务。

“发布必填”表示本工具在准备发布时检查该字段，“选填”表示本地不拦截；“需到原站设置”表示还需在原站确认或填写，保存本地选项不等于已经同步到平台。

专注写作只显示源码，双栏对照显示源码与预览，阅读预览显示排版正文。切换视图保留编辑器的当前内容和撤销历史。格式工具栏可给选中文字添加加粗、斜体、标题、列表、引用、行内代码或链接。

| 快捷键         | 作用                   |
| -------------- | ---------------------- |
| Ctrl+B / Cmd+B | 加粗选中文字           |
| Ctrl+I / Cmd+I | 斜体选中文字           |
| Ctrl+S / Cmd+S | 立即保存当前待写入内容 |
| Ctrl+Z / Cmd+Z | 撤销源码编辑           |

连续输入在停顿约 350 毫秒后合并写入本地存储，离开编辑页或打开发布预览会先保存。关闭浏览器前请确认显示“本地已保存”；浏览器或系统被强制终止时，内存中尚未落盘的输入仍可能丢失。

多窗口编辑发生冲突时，旧窗口不会覆盖其他窗口已保存的内容。保存失败会保留页面与未保存编辑，后续写入不会掩盖错误：

1. 存储暂时不可用时，可点击“重试保存”。
2. 并发冲突时，可用“另存为新稿”保存当前母稿和所有平台版本，再打开原稿比较。
3. “导出当前版本”也能携带尚未落盘的当前内容，作为单个版本的外部副本。

Markdown 文件与图片目录的批量导入会先完整校验再写入。一篇导入失败时，该批稿件和新图片均不写入；已有内容不受影响。

## 内容导出与工作空间备份

在编辑器“稿件工具”中点击“导出当前版本”，或在内容库选择稿件后点击“导出所选”。ZIP 中每个版本包含：

- `正文.md`：图片引用改为 `images/...` 相对路径。
- `images/`：正文、配图列表与封面使用的本地图片。
- `稿件信息.json`：标题、配图顺序，以及已保存的平台设置。

解压后可直接使用 Markdown 编辑器打开，也可把一个版本的目录重新导入 zMatrix。重新导入 Markdown 时，标题按正文一级标题或文件名解析，不自动恢复 JSON 中的平台设置和配图顺序；外链图片保留原地址，不自动下载。

内容导出用于携带稿件，不包含任务、发布记录、数据或评论。需要完整迁移、恢复时，请使用“设置 → 数据与备份”里的 ZIP 备份。备份格式、数据库名称与扩展身份保持兼容。

## 发布队列

发布准备面板记住上次的平台和操作方式，仍需你逐次确认。全选选择六条准备路径；LINUX DO 继续使用人工发布辅助。缺少标题、分类、标签、摘要或封面时可直接在面板补充；正文与配图可返回平台版本编辑，平台选择保留。完成预览后，主要操作立即准备，次级操作“加入队列，稍后执行”只创建待办。

博客园会先开启提交保护，再自动填入内容。页面底部会提示保护状态，等待期间不会交出提交权限。确认内容后，亲自点击原站的“发布”或“存为草稿”，工作台才交还这一次操作；脚本模拟点击无法解除保护。博客园选择“保存草稿”时，也需要这一步人工点击；队列会明确显示尚未保存，不会将填入等同于保存成功。

执行队列会先核对前后台版本和发布协议。替换扩展文件后必须在 Edge 扩展管理中重新加载，并重新打开工作台；旧后台无法通过核对时不会收到新的执行请求。

队列默认显示“待处理”，包括未执行、失败与等待核实的任务；“执行中”和“历史记录”分别查看当前进度及已结束任务，再按平台和标题缩小范围。“执行筛选内任务”只启动当前筛选中允许执行的任务，顺序仍按创建时间排列。结果待核实或等待手动发布的任务不会因此重新提交。

失败或历史已取消任务如果已经打开原站编辑页面，仍需核实原站结果，不能通过取消、重试或重新排队来重复提交。后台已领取的任务不能被旧页面取消；可以暂停队列，然后按提示核实。

真实平台的最终发布仍由用户在原站手动完成。

未执行任务支持“取消并移除”，历史记录支持单条删除和批量清理当前筛选结果。删除任务记录不会删除原站内容或本地发布登记，已完成内容保留独立的防重凭据。存在原站活动但结果尚未核实的任务不能清理。

## 数据与互动

文章数据和评论共用一个入口，内部切换页签。文章卡片的更多菜单可修改登记标题与母稿关联，也可删除本地登记。删除登记会停止跟踪并清除其指标、评论缓存；支持勾选后批量删除，不影响原站文章、原站评论或本地稿件。

## 素材清理

在“设置 → 数据与备份”点击“检查可清理素材”，查看图片数量和可释放空间，确认后清理。检查覆盖母稿、回收站、平台独立内容、封面、任务及发布快照；刚导入或重新使用的图片有 24 小时保护期。确认时会再次核对引用，不会删除期间刚被使用的图片。

回收站和防重凭据会随完整 ZIP 备份保留。旧版 ZIP 仍支持导入；升级后的数据库使用 v2 结构，建议继续使用 0.3.0 或更新版本。
