# v0.2.1 平台字段与博客园提交保护

日期：2026-09-30。基于 v0.2.0，保留扩展身份、`tonggao-workbench` 数据库和原有备份格式。

## 改动与行为

- 分类使用候选项；掘金固定分类来自官方分类接口，账号分类支持读取已打开原站的可见选项和本地历史值。
- 可删除标签、分隔符批量添加和去重；摘要从正文开头提取并可撤销；字段标注必填、选填和原站设置。
- 发布预览全选六条路径，包含恢复使用的博客园；LINUX DO 继续人工辅助。
- 博客园任务先打开空白标签页，注册 document_start 隔离脚本并安装标签页级浏览器请求规则，再导航到新建编辑页。规则拒绝博客园非 GET/HEAD/OPTIONS 请求，显式覆盖顶层表单、XHR/fetch、子框架和 beacon 等资源类型。唯一写入例外是指定的图片上传接口。
- 确认规则与隔离脚本就绪后才填入正文。填入及发布准备不点击发布，不解除规则；保存草稿也改为原站手动点击，并返回待处理状态。
- 用户在原站亲自点击发布／草稿按钮时，隔离脚本阻止原事件继续传播，经后台核对主框架、标签页、任务、令牌和就绪状态后交还控制，再重放该用户刚点击的同一个控件。脚本生成的点击不能触发交接；交接失败仍不点击。
- 页面操作只允许受保护的新建博客园编辑页，既有稿件拒绝覆盖。已有远端活动的队列任务不能直接重跑。核实结果不刷新博客园页面。
- 前后台版本与发布协议必须匹配才能运行队列。

## 验证

- Vitest 11 个文件、109 项测试通过。类型检查、Edge 生产构建及格式检查用于发布前验证。
- 自动回归覆盖规则安装顺序、安装失败停止、规则缺失或范围缩小拒绝、后台重入、错误令牌／其他扩展／子框架拒绝、不同任务隔离、页面导航与重复交接、脚本点击和表单事件、草稿交接及内容核对。
- 本地浏览器使用 `tests/fixtures/cnblogs-handoff.html` 验证真实点击：脚本点击后提交数为 0；模拟后台失败后仍为 0；用户点击且后台成功后，原生点击与提交各 1 次。该页面使用模拟后台，并无真实发文或网络规则执行。
- 前一轮已验证分类选择、标签增删与持久化、摘要提取／撤销、桌面和窄屏布局。截图使用本地内置示例稿，不含私人账号数据。
- 公开 0.1.2 包不含更新检测代码或 GitHub API／alarms 权限。0.2.0 起默认每 6 小时检查包含开发预览的版本；用户仍自行决定下载与安装。0.1.2 需手动升级一次。

## 验证边界

用户报告的 0.1.2 误发布事件仍缺文章链接和队列运行证据，不能归因到某一条旧代码。此版修复的是准备阶段缺少独立提交拦截的问题；本地回归不能证明真实 Edge 与博客园全流程已通过验收。原站分类读取、图片上传、保存后的远端状态和其他平台流程仍按 `acceptance.md` 记录。

## 包与升级

发布产物为 `zMatrix-edge-0.2.1.zip`、`zMatrix-source-0.2.1.zip`、许可证汇总及 `SHA256SUMS.txt`。发布前校验包内版本、身份、保护脚本和权限，发布后校验下载文件哈希。

升级先备份，再覆盖原加载目录，最后重新加载并重新打开工作台；不要卸载原扩展。0.2.1 增加用于阻止博客园意外提交的 `declarativeNetRequestWithHostAccess` 权限，不静默扩大平台站点访问。
