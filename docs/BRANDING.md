# zMatrix 图标

采用用户选定的 A「经典四色」：四块错页围绕 z 形留白排列，右上角折页表达内容创作；不同颜色表达多平台协作。

规范源文件：`public/icon/zmatrix.svg`。根据选定概念图重绘为透明背景矢量，保留曲线、折角与四色位置，去除生成图的背景和纹理。

| 位置 | 颜色 |
| --- | --- |
| 左上、折角 | `#2D64E8` 蓝 |
| 右上 | `#25A982` 绿 |
| 左下 | `#F2B647` 金 |
| 右下 | `#EC6E62` 珊瑚红 |

修改 SVG 后运行 `npm run icons`，生成 16、32、48、128、256 像素透明 PNG。提交源文件和 PNG，普通构建不需要重新生成图标。

扩展清单和工具栏使用 PNG，工作台使用 SVG，标签页使用 32 像素 PNG。更新本地构建后在 Edge 扩展管理页重新加载扩展，并刷新已打开的工作台标签页。
