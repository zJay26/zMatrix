# 发布队列清理验证（2026-10-06）

## 行为

- 等待手动发布、发布设置待核对、已提交、审核中、结果待核实，以及有原站活动的失败、取消或暂停任务，支持单条“放弃跟踪并移除”和勾选批量清理。
- 确认框列出尚未确认结果的任务数量，说明仅移除本地队列记录；保留内容库稿件、发布登记、原站内容和标签页。
- 已完成或放弃跟踪的任务留下同一平台、模式、内容指纹的防重凭据，并随现有备份保存。未开始且没有原站活动的任务仍可取消后重新排队。
- 批量授权按任务 ID 保存；确认期间其他任务开始执行或产生原站活动时，整批回滚，不扩大放弃跟踪的授权范围。
- 准备、提交、核实中的任务不能清理。后台核实使用事务领取状态，失败时恢复原状态，避免留下无法清理的核实状态。
- 内容库删除继续沿用原有保护规则；清理操作不会解除博客园发布保护。
