## 本地自动验证

`npm run typecheck` 通过；0.1.2 的 Vitest 45 项通过，包括 12 项手动发布保护测试与 2 项更名后的自动备份兼容测试：

- 母稿继承、独立覆盖、不可变快照、并行编辑冲突。
- 同批次和历史重复任务拦截；提交中断恢复为待核实，禁止重试。
- 中文、Markdown、KaTeX、表格渲染，AST 转图片范围，HTML 清理和外链图片拦截。
- 配套图片、引用式图片、普通链接、嵌套目录和缺失素材导入。
- 正文和图片二进制备份、恢复任务暂停、损坏校验、已有本地记录优先。
- 相同远端文章的合并与评论重新关联；备份目录权限失效；v1 数据库重开。
- 备份写入期间继续编辑，覆盖时间仍绑定原快照，最新内容需要下一次备份。
- 评论分页去重、已读状态和父评论关系保留。
- 原站域名检查、账号限制、保存按钮识别、已有稿件保护和歧义按钮停止。
- 隐藏或近乎透明的重复控件不作为操作目标；审核说明不误判为审核状态。
- 六条路径的旧自动发布命令均拒绝；准备发布不触发最终按钮 click 或 submit。
- 分类、封面、必填项未完成不能标记“等待手动发布”；等待手动处理的任务重启后不能重跑。
- 核实手动发布结果时不刷新原站待发布页面。
- 更名后承接旧自动备份文件，且权限错误不会被文件名回退机制掩盖。

`npm audit` 当前报告 0 项漏洞。已修正 Mermaid 依赖链中的 lodash-es 漏洞版本。
